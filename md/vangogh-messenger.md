## 游戏概览

《星夜之梦》是一款在 Unity 中制作的 2D 横版解谜游戏。玩家扮演一位戴着帽子、身体半透明的信使，带着梵高写给弟弟提奥的信，穿越由画作构成的世界，最终将信投入邮箱。

信使被设定为梵高想象中的角色。游戏以书信串联场景与叙事，并将绘画转化为解谜方式：玩家使用颜料创造可攀爬的路径，在探索中逐渐接近画作背后的情绪与内心世界。

## 叙事与场景设计

旅程从《星夜》展开。开场通过分镜与动画交代人物经历和信件的来由；结尾以信件穿行于画作之间的动画收束故事，回应贯穿游戏的投递任务。

场景与角色美术取材于梵高的画作和素描，并使用基于 ComfyUI 的图像生成统一视觉风格。在《星夜》场景中，团队将画面拆为 **5 个图层**，通过 Unity 脚本控制各层随玩家移动产生不同速度的位移，让平面绘画具有空间层次。

探索过程中，玩家会听到梵高书信的旁白片段。配音取材自 BBC 纪录片，由本尼迪克特·康伯巴奇朗读，与场景中的画作和动画共同承担叙事。

## 玩法与操作

**用颜料绘制路径**是核心机制。玩家向向日葵喷洒颜料，生成可攀爬的路线；按住 **Shift** 沿路径攀爬，抵达普通跳跃无法到达的平台。颜料可以擦除，便于重新规划路线，让绘画同时成为观察、尝试与解谜的工具。

- **暗云障碍**：首次触碰后，画面失去色彩，持续 2 秒；在此期间再次触碰，角色死亡。全屏视觉反馈同时提示玩家当前的危险状态。
- **乌鸦与风**：乌鸦可以充当弹跳平台，帮助玩家越过间隙；风将角色托向高处，与颜料路径一起构成关卡中的移动方式。
- **信件与邮箱**：携带信件穿过关卡并完成投递，是探索与解谜的共同目标。

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D |
| 跳跃 | 空格 |
| 向向日葵喷洒 / 擦除颜料 | 鼠标左键 / 右键 |
| 沿颜料路径攀爬 | 按住 Shift |

## 我的工作：风格化渲染

我主要负责通过 Shader 将角色与画作的视觉风格统一，并实现特定游戏时刻的全屏效果。

- **3D 角色的 2D 风格化**：以 Mixamo 的 3D 模型为基础，在 Shader 中叠加主色、笔触噪声和画布纹理，使角色呈现绘画质感，同时保留 3D 动画的流畅度，降低角色动画的制作成本。
- **与玩法联动的画面效果**：实现触碰障碍后的全屏灰度，以及关卡终点的转场，让画面变化承担状态提示与叙事衔接的作用。
