# 视觉与交互规范

## 设计方向

Less is more。以姓名、简短介绍、关注方向与项目记录构成页面。不使用宣传标语、全屏照片、渐变背景、悬浮胶囊导航或入场动画。项目图像作为内容的一部分展示。

## 色彩与排版

- 暖白背景 `#faf9f6`，深灰正文 `#292b28`，次级文字 `#60635b`。
- 细分隔线 `#e2e2da`，低饱和橄榄色 `#626e57` 用于细线图标与焦点。
- 姓名、页面和项目标题使用 Iowan / Palatino / 宋体类衬线字体；正文使用 Avenir Next / 系统无衬线字体，不依赖外部字体服务。
- 主要正文为 16–18px，详情正文为 17px；辅助标签为 13–15px。
- 个人照片使用无边框、无配字的矩形展示，在桌面端与介绍并排、移动端独立展示。三个关注方向分别采用轨道、坐标曲线与分支节点图标。
- 内容宽度最大 1000px，详情正文最大 800px。通过留白、字号与字重区分层级。

## 内容与双语

首页并列呈现三个关注方向：元宇宙、AI 与虚拟现实；数学与数据分析（医疗数据集）；游戏开发与策划。已有项目单独展示，不将关注领域描述为已完成成果。

介绍区域列出本科与硕士教育经历，包括院校、学位、专业和起止年份，随中英文切换。

默认使用简体中文。页头可随时切换英文，选择保存在本地。导航、页面文案、项目简介、现有 Markdown 详情、状态提示和页面元信息均跟随语言变化。

## 响应式与可访问性

- 桌面端关注方向为三栏，600px 以下改为单栏。
- 项目列表在桌面端使用小图与简介，移动端使用图片在上、文字在下的布局。
- 保留键盘焦点、跳到主要内容链接、语言按钮的选中状态和页面语言属性。
- 图片使用响应式缩略图，保持原始比例与完整画面；详情不超过原始分辨率放大。
- 图片加载失败时先回退到原图，详情支持重试；视频保留封面，点击后才加载播放。
- 380px 以下的导航分成两行，避免英文挤压。
- 手机端简介下提供「浏览项目」锚点入口。页面内跳转支持键盘焦点，并尊重减少动态效果设置。
- 项目链接沿用标题下划线，箭头以 180ms 移动 2px；键盘焦点提供同等反馈，减少动态效果时取消位移。
- 项目简介与个人职责分行呈现。职责只展示已有记录，乌镇列表封面聚焦染坊手部交互；详情原图保留完整画面。
- 三个及以上二级标题的详情自动展示文字目录，标题锚点按章节顺序编号。详情页末尾链接到下一项目，最后一项回到第一项。
- 浏览器前进、后退恢复阅读位置；详情的「返回项目」也恢复最近的项目列表位置。异步内容就绪后再定位，新的导航取消旧的定位等待。
